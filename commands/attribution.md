# Attribution

Record what shaped the workflow — credit ideas / adapted work as **attribution**, reference docs as
**resources** — in `ATTRIBUTION.md`.

## Instructions

Apply the **`attribution` skill** for the resource(s) in `$ARGUMENTS` (or the one just shared):

1. **Classify** — attribution (provider blog / novel-idea blog / someone's adapted file), resource
   (official docs, help files, wiki), or neither (didn't shape a file). Recommend, then ask the user
   to confirm.
2. **Trace to origin** — if a blog is just reconceptualizing an existing idea, offer to find the
   original source and attribute that instead.
3. **Record** — add/update the row in `ATTRIBUTION.md`: the file(s) built (the skill + any linked
   commands/agents), the attribution, and any resources. Verify links resolve.

## Rules

- Ask, don't assume — offer attribution / resource / neither, and offer to find the origin.
- Credit the origin of an idea, not a blog that restates it; credit a blog only for a genuinely novel idea.
- Only record resources that actually shaped a file.
