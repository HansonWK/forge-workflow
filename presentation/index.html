Forge

A shared development workflow you and the AI forge to fit your project — and keep improving together.

What it is

A workflow that lives
in your repo

  • Markdown commands, skills, and agents committed to .claude/
  • Every developer shares the same workflow, quality gates, and conventions
  • Version-controlled — improvements go through PRs like any other code
  • npx forge-workflow install, then /install to configure it for your stack
The concept

You don't install it.
You forge it.

Ships as

Your forged workflow
  • /install stands up a baseline tailored to your language, tools, and tracker

  • Skills are the single source of truth; the loop self-verifies before you review
  • It starts good and gets sharper the more you use it

Keeping it sharp

Two ways it evolves

/customize

You add

You-initiated · additive
  • Author a new skill, command, or agent
  • Larger changes — your own logs, dashboards, or KQL
  • Encodes a recurring need once, instead of re-typing it
/recalibrate

Claude corrects

Claude-initiated · corrective
  • Fires when Claude gets pushback on the workflow
  • Routes the fix to the right home — memory vs a shared file
  • Makes a correction stick so it doesn't recur

Both keep the workflow encoding how your team actually builds.
